# Mine / Ledger — 10스테이지 증강 지뢰찾기

현재 릴리스: **v1.0.1+build.5 — 사이드 패널 잘림 수정**. 최신 강화 규칙은 `UPGRADES.md`를 참고하세요.

브라우저 플레이: https://Kimminsung415.github.io/minesweeper_Roguelike/

링크를 연 사람마다 독립적으로 플레이합니다. 계정·게임 서버·멀티플레이 연결은 필요 없습니다.
PC의 Chrome/Edge 등 WebGL 2 지원 브라우저에서 플레이하세요. 처음에는 웹 엔진을 내려받아 잠시 로딩합니다.
웹 배포 파일은 `docs/`, 배포/업데이트 방법은 `WEB_DEPLOY.md`에 있습니다.

인수인계 프로젝트를 기반으로 정리한 Godot 4.x + GDScript 프로토타입입니다.
액티브 13개, 패시브 13개, 디버프 12개와 10스테이지 최종 승리를 구현했습니다.
전체 효과와 적용 순서는 `AUGMENTS.md`, 강화 상점과 최신 변경은 `SHOP_UPDATE.md`에 있습니다.

## 바로 플레이 (Windows 휴대용 패키지)
1. `MineLedger_v0.1.0_build001_Windows.zip`을 폴더에 모두 압축 해제합니다.
2. `PLAY.cmd`를 더블 클릭합니다. 별도 Godot 설치 없이 게임 창이 열립니다.
3. 수정하려면 `EDIT.cmd`를 실행하거나 Godot에서 `project.godot`을 가져옵니다.

휴대용 패키지는 공식 Godot 4.5.1 일반 실행 파일과 프로젝트 소스를 함께 묶었습니다.
독립 게임으로 export한 EXE가 아니라, 동봉된 Godot으로 프로젝트를 직접 실행합니다.
소스 ZIP에는 엔진을 포함하지 않습니다. 아래 일반 실행 방법을 사용하세요.

## 실행
1. Godot 4.x 일반 버전을 설치합니다. .NET 버전이나 추가 플러그인은 필요 없습니다.
2. ZIP 파일을 압축 해제합니다.
3. Godot 프로젝트 관리자에서 '가져오기'로 project.godot을 선택합니다.
4. 프로젝트를 열고 F6(현재 씬) 또는 F5(프로젝트)를 누릅니다.
5. UI는 한국어입니다. SIL OFL 라이선스의 Noto Sans KR 폰트를 프로젝트에 포함합니다.

## 개별 강화

보유 증강 카드 → 상세창의 강화 버튼에서 Lv.4까지 강화합니다. 성공률은 30% / 20% / 10%, 가격은 현재 파기 비용의 6 / 12 / 24배입니다. 각 증강별로 따로 계산하며 전체 범위 강화 상점은 대체되었습니다.

## 조작
- 좌클릭: 타일 파기
- 공개된 숫자 칸 좌클릭: 주변 지뢰 확인 완료 및 전체 비용 충족 시 주변 일괄 파기
- 우클릭: 깃발 설치/해제
- COMMIT · 깃발 정산: 미정산 깃발 일괄 검사
- Space / Enter / 숫자패드 Enter: Commit 버튼과 동일하게 미정산 깃발 일괄 검사. 누르고 있어도 반복 실행되지 않습니다.
- 상세창·보상/증강 선택·능력 대상 선택 중에는 Commit 단축키가 정산하지 않습니다. 통신 장애 등 기존 Commit 제한도 유지됩니다.
- 상단 스마일 버튼: 즉시 새 런 시작 (체력/골드/스테이지 초기화)
- 런 포기: 현재 런 포기
- 큰 보드는 보드 영역에서 스크롤할 수 있습니다.
- 오른쪽 보유 증강 카드: 종류와 사용 여부에 관계없이 클릭하여 상세보기
- 오른쪽 ‘상점’ 버튼: 강화 티켓 판매 위치로 이동. 첫 파기 후 골드로 구매하면 즉시 추첨
- 강화 티켓: 처음 성공률 10%, 성공하면 중첩 가능한 영역 확장 +1. 실패해도 골드 소모
- 구매 후 약 2.2초간 강화 연출 → 성공/실패 공개. 결과는 확인 버튼 또는 Enter/Space/Esc로 닫기
- 연출 중에는 구매·파기·Commit·능력 사용이 잠깐 잠깁니다. 골드와 추첨은 구매당 한 번만 처리됩니다.
- 영역 확장은 영역전개·스캐너·안전 굴착의 반경을 레벨당 1칸 늘림. 현재 범위/가격/확률을 상점과 상세창에 표시
- 액티브: 상세창의 ‘능력 사용’ 또는 ‘대상 선택’ 버튼으로 사용 (첫 파기 이후, 스테이지당 각 1회)
- 영역전개/스캐너/안전 굴착: 능력 카드 → 상세창 ‘대상 선택’ → 보드의 대상 칸 좌클릭
- 목표 선택 취소: 우클릭 또는 Esc. 취소 시 횟수 미소모
- 오른쪽 패널에서 스크롤하면 보유 능력 카드가 표시됩니다. 클릭하면 전체 설명과 현재 상태를 확인합니다.

## 보유 증강 상세보기

액티브·패시브·디버프 카드를 누르면 큰 그림, 줄바꿈된 전체 효과 설명,
현재 상태와 사용 방법/주요 상호작용을 표시하는 상세창이 열립니다.
설명이 길면 창 안에서 스크롤할 수 있습니다.

- 설명을 여는 것만으로 골드·능력 횟수·보드·난수 상태가 바뀌지 않습니다.
- 액티브는 별도의 사용 버튼을 눌러야 발동합니다. 대상 지정 능력은 그 뒤 보드에서 칸을 고릅니다.
- 첫 파기 전이나 이미 사용한 액티브도 설명을 볼 수 있으며 사용 버튼만 비활성화됩니다.
- 부활권 소모 여부, 액티브 남은 횟수, 공명 사용 횟수, 무료 파기 잔여량 등을 표시합니다.
- 패시브/디버프는 자동 적용 효과이므로 사용 버튼이 없습니다.
- 닫기 버튼, Esc, 창 바깥 클릭으로 닫습니다. 설명창 안의 Tab 이동은 창 안에 유지됩니다.
- 대상 선택 중 설명을 보고 닫아도 기존 대상 선택은 취소하거나 소모하지 않습니다.
- 설명창을 연 동안 뒤쪽 보드 클릭은 차단됩니다.

## 10스테이지 선택 흐름

- 1·3·5·7·9 클리어: 버프 3개 중 1개. 액티브와 패시브가 반드시 하나씩 포함됩니다.
- 2·4·6·8 클리어: 디버프 2개 중 반드시 1개.
- 증강 선택 뒤 골드 또는 HP 회복을 별도로 선택하면 다음 스테이지가 시작됩니다.
- 선택한 효과는 다음 스테이지 시작부터 런 종료까지 적용됩니다.
- 같은 효과를 두 번 획득할 수 없습니다. 소모한 부활권도 재등장하지 않습니다.
- 10 클리어: 최종 승리. 추가 증강/골드/회복 선택 및 11스테이지 없음.
- 마지막 스테이지에는 버프 5개, 디버프 4개가 누적됩니다.

## 클래식 화면
- 회색 입체 테두리와 간격 없이 붙어 있는 타일
- 왼쪽 금화 그림 + 빨간 7세그먼트 숫자판: 현재 GOLD (시작 030)
- 오른쪽 HP 게이지: 현재/최대 HP, 남은 체력에 따라 초록/노랑/빨강으로 변경
- HP 바로 아래 큰 카운터: 남은 전체 지뢰 / 전체 수, 특수(은신) 지뢰 잔여 / 전체 수
- 골드·HP·지뢰 카운터는 고정 영역에 있어 큰 보드를 스크롤해도 계속 보입니다.
- 남은 지뢰는 Commit·직접 폭발·안전 굴착 등으로 확인한 지뢰를 차감합니다. 미검증 깃발은 차감하지 않습니다.
- 특수 지뢰는 현재 은신지뢰를 뜻하며, 남은 전체 지뢰 수에도 포함됩니다.
- 골드가 999를 넘으면 자릿수가 늘어나며 실제 값을 전부 표시
- 빨간 깃발: 미정산, 초록 깃발과 체크: 정산 완료
- 검은 지뢰 아이콘: 지뢰, 빨간 타일의 지뢰: 직접 파기로 폭발
- 고전 숫자 색상: 1 파랑, 2 초록, 3 빨강 등
- 스마일은 클리어 시 선글라스, 게임오버 시 실패 표정으로 변경
- 영역전개: 고죠 사토루의 기술 시전 일러스트. 다른 29개 효과: 고유한 아이콘
- 보유 카드와 선택 카드에 같은 그림을 표시. 보유 카드를 클릭해 그림/효과/현재 상태를 확대 확인
- 영역전개는 공식 애니메이션 33화 원본 장면 `assets/domain_gojo_official.jpg` 사용. 출처는 `assets/IMAGE_SOURCES.md`
- 이미지와 한글 폰트는 게임 데이터에 포함됩니다. 브라우저는 웹 실행 파일을 처음 내려받고 게임을 실행합니다.

## 숫자 칸 주변 파기 (Chord)

공개된 숫자 칸을 누르면 주변의 미공개·미확정·깃발 없는 칸을 순서대로 팝니다.
숫자만큼의 주변 일반 지뢰가 확인되어 있어야 합니다. 수동/자동 Commit한 지뢰,
직접 밟아 폭발한 지뢰, 안전 굴착으로 확정한 지뢰를 모두 포함합니다.
빨간 미정산 깃발만 꽂은 칸은 조건에 포함하지 않습니다. 폭발/확정 지뢰는
다시 파거나 피해·보상을 반복하지 않으며, 남은 주변 칸에만 비용을 지불합니다.

시작 전에 모든 대상 칸의 비용을 확인합니다. 굴착세와 남은 무료 파기 효과를
반영하며, 전체 비용을 지불할 수 없으면 한 칸도 파지 않고 카운터도 유지합니다.
예상 연쇄 공개나 미래 정산 수입은 선불 가능 골드로 계산하지 않습니다.
실행 중 연쇄 공개/공명으로 먼저 열린 칸은 중복 과금하지 않습니다.
숫자 칸 툴팁에서 대상 수, 필요 골드, 현재 조건을 볼 수 있습니다.

각 파기는 일반 직접 파기이므로 재생/공명/지반/방폭 등의 효과와 횟수가 적용됩니다.
사망 또는 클리어 시 나머지 동작을 멈춥니다. ?로 가려진 숫자와 빈칸에는 적용되지 않습니다.
은신지뢰는 숫자에서 빠지므로 주변 파기로도 폭발할 수 있습니다.

## 구현된 규칙
- 시작 HP: 10, 시작 재화: 30
- 지뢰 직접 클릭: HP -2, 파기 비용도 지불
- 잘못된 깃발 Commit: 타일당 기본 HP -2, 고폭약 보유 시 -3. 방폭복 미적용
- 파기 비용: `2 × 스테이지 + floor((스테이지 - 1)² / 4)`
- 지뢰 정산 보상: 현재 파기 비용의 2배
- 깃발/확정 지뢰 칸 클릭: 비용 없음. 공개된 숫자 칸은 주변 파기 조건 확인
- 첫 유효 파기 시 지뢰 생성: 클릭한 칸과 이웃 8칸에 지뢰가 없음
- 첫 파기 전 깃발 설치 가능, Commit은 첫 파기 후 활성화
- 빈칸 연쇄 공개: 추가 비용 없음. 깃발 칸은 연쇄 공개에서 제외
- 올바른 깃발은 초록 깃발/체크로 고정되어 재정산 및 해제 불가
- 직접 클릭해 폭발한 지뢰는 빨간 바탕 지뢰 표시, 재정산 보상 및 반복 피해 없음
- 잘못된 깃발은 제거하고 안전 칸 하나만 공개(연쇄 공개 없음)
- 인접 지뢰 숫자에는 폭발/정산된 지뢰도 계속 포함: 지뢰 자체는 제거하지 않음
- 모든 지뢰를 Commit하면 클리어. 안전 칸 전체 공개는 필수가 아님
- 마지막 지뢰의 정답 보상을 지급한 뒤 클리어 보상을 선택. 폭발/안전 확정 지뢰는 Commit으로 무보상 처리 완료
- 한 행동의 HP 감소 및 수입을 모두 처리한 뒤, HP 0 여부를 클리어보다 우선 판정
- 클리어 보상: 다음 스테이지 파기 비용 6회분 재화 또는 HP 4 회복
- 기본 최대 HP는 10. 강화 심장·쇠약·생명력 주입으로 변경 가능. HP와 재화는 다음 스테이지로 이어짐
- 보드 가로와 세로: 둘 다 8에서 시작해 매 스테이지 각각 2 증가
- 보드 크기: 8×8 → 10×10 → 12×12 → 14×14 …, 기존 크기 상한 제거
- 지뢰 수: `floor(전체 칸 수 × 목표 밀도)`
- 목표 지뢰 밀도: 18%에서 시작해 매 스테이지 1%p 증가, 최대 25%
- 실제 밀도는 지뢰 수를 정수로 내림하므로 목표보다 조금 낮을 수 있음
- 런은 10스테이지에서 종료. 세이브, 사운드, 모바일 전용 조작은 미포함

## 재화 부족 처리
현금이 파기 비용보다 적어도 깃발과 Commit은 무료로 사용할 수 있습니다.
따라서 잔액 부족 즉시 게임오버로 처리하지 않습니다.

아직 정산 가능한 지뢰를 전부 정산해도 파기 비용에 못 미치고,
남은 모든 안전 칸을 오답 Commit으로 공개하기에도 HP가 모자라며,
무료 파기/구조 액티브/부활 같은 진행 수단도 없으면 자동 파산합니다.
HP가 0이 되면 실패하므로 안전 칸을 HP로 공개하려면 최종 HP가 1 이상이어야 합니다.
최초 파기 비용조차 없는 새 스테이지는 즉시 파산합니다.
진행을 포기하려면 런 포기를 사용할 수 있습니다.

보상 화면은 실제 회복량, 선택 후 잔액/체력, 다음 스테이지 비용을 표시합니다.
회복 선택 후 다음 첫 파기를 할 재화가 없으면 경고를 표시하며, 선택 시 즉시 파산합니다.
체력이 가득 찼을 때 회복을 선택하면 회복량은 0이며 그대로 다음 스테이지로 갑니다.

이 판정은 플레이어가 논리적으로 풀 수 있는지를 검사하는 추론 솔버가 아닙니다.
남은 지뢰 정산과 HP 소모까지 고려한 수학적 진행 가능성만 확인합니다.

## 의도적으로 남긴 밸런스 특성
잘못된 깃발의 안전 칸을 공개하므로 HP로 파기 비용을 대체할 수 있습니다.
이는 이번 프로토타입에서 허용한 규칙이며 추후 밸런싱 대상입니다.
첫 클릭은 안전하지만 이후 모든 선택이 추측 없이 풀리도록 보장하지는 않습니다.

## 테스트 실행
Godot 실행 파일을 PATH에 등록한 경우 프로젝트 폴더에서:
    godot --headless --path . --script res://smoke_test.gd

휴대용 패키지는 `TEST.cmd`로 핵심·증강·주변 파기·단축키·상점 검사를 순서대로 실행합니다.

증강 검사만 실행:
    godot --headless --path . --script res://augment_test.gd

GUI 검사(실제 창이 열리고 검사 후 닫힙니다):
    godot --path . --script res://gui_test.gd

휴대용 패키지는 `GUI_TEST.cmd`로 GUI 검사를 실행할 수 있습니다.
GUI 검사는 스테이지 클리어 화면을 빠르게 확인하기 위해 테스트용 상태/선택지를 구성합니다.
실제 입력 이벤트로 파기/깃발/Commit, 증강 카드, 목표 선택, 보상, 재시작을 검증합니다.
기본 캡처 경로는 `user://qa`이며 `-- <출력폴더>` 인수로 바꿀 수 있습니다.
